# 线性回归理论基础

## 1. 什么是线性回归？

线性回归是机器学习中最基础的监督学习算法，用于预测连续值目标变量。

**核心思想**：找到特征与目标之间的线性关系
**数学表达**：y = θ₀ + θ₁x₁ + θ₂x₂ + ... + θₙxₙ

## 2. 应用场景

- 房价预测
- 股票价格预测
- 销售额预测
- 任何有连续输出的问题

## 3. 关键概念

### 3.1 特征(Features)与目标(Target)
- 特征：输入变量（X），如房屋面积、卧室数量
- 目标：输出变量（y），如房屋价格

### 3.2 损失函数(Loss Function)
衡量模型预测误差的函数：
- 均方误差(MSE)：最常用
  $$ MSE = \frac{1}{m}\sum_{i=1}^{m}(y_i - \hat{y}_i)^2 $$

### 3.3 优化算法
- 最小二乘法：解析解
- 梯度下降：迭代优化

## 4. 评估指标

| 指标 | 公式 | 含义 |
|------|------|------|
| MSE | $\frac{1}{n}\sum(y_i-\hat{y}_i)^2$ | 均方误差，越小越好 |
| R² | $1 - \frac{SS_{res}}{SS_{tot}}$ | 决定系数，0-1，越大越好 |

## 5. 优缺点

**优点**：
- 简单易懂，计算速度快
- 可解释性强
- 是许多复杂模型的基础

**缺点**：
- 只能处理线性关系
- 对异常值敏感
- 需要特征工程
