## 📈 算法实现

### 核心算法：梯度下降线性回归

本项目手动实现了线性回归算法，主要包含以下组件：

1. **模型初始化**：随机初始化权重和偏置
2. **前向传播**：计算预测值 ŷ = Xw + b
3. **损失计算**：使用均方误差（MSE）作为损失函数
4. **反向传播**：计算权重和偏置的梯度
5. **参数更新**：使用梯度下降更新参数

### 关键技术点
- 数据标准化处理
- 学习率动态调整
- 早停机制（防止过拟合）
- 正则化选项（可选）

## 📊 模型评估指标

模型性能将通过以下指标评估：

1. **均方误差（MSE）**：预测值与真实值差异的平方平均值
2. **R²分数**：模型解释的方差比例，越接近1越好
3. **残差分析**：检查预测误差的分布
4. **特征重要性**：分析各特征对预测的贡献度

## 🔍 特征重要性分析

通过分析线性回归模型的系数，可以了解各个特征对成绩的影响：

1. **系数大小**：绝对值越大，影响越显著
2. **系数符号**：正号表示正相关，负号表示负相关
3. **标准化系数**：比较不同量纲特征的重要性
