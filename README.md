# Machine Learning Learning Repository

东南大学吴健雄学院 夏滔 机器学习自学记录

## 项目结构

| 目录 | 用途 |
|------|------|
| `projects/` | 按主题分类的完整项目 |
| `notebooks/` | Jupyter Notebook实验记录 |
| `data/` | 数据集（小样本） |
| `docs/` | 学习笔记和理论推导 |
| `src/` | 可复用的代码模块 |
| `scripts/` | 实用脚本 |

## 学习路线

### 第一阶段：基础算法
1. 线性回归
2. 逻辑回归
3. 决策树与随机森林

### 第二阶段：进阶技术
1. 神经网络
2. 支持向量机
3. 聚类算法
